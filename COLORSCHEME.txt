THE PALETTE — five colours, nothing else
========================================

  #263640   dark slate    backgrounds, text, axes, ink
  #ffffff   white         panel backgrounds, bar edges
  #5096c0   blue          the model
  #e87878   red           the truth
  #e9c46a   yellow        what the model cannot see

Plus two neutrals, which are furniture rather than colour:

  #9e9e9e   grey          controls, ablations, reference lines
  #eeeeee   pale grey     raster bands, gridlines


WHAT EACH COLOUR MEANS, ON EVERY SLIDE
======================================

blue      the student, the model, the connectome-constrained fit — the thing we built
red       the teacher, the true network, ground truth — the thing we are trying to match
yellow    the unobserved population: neurons the model must predict without being shown
slate     ink. Axis labels, titles, and any single-condition series
grey      every control and every ablation, told apart by line style and shade, never hue


RULES
=====

1. A colour means the same thing in every figure. If two things need distinguishing and
   both are "the model", use line style or shade, not a new hue.
2. Controls are grey. The coloured bar or line is the condition we are arguing for; the
   controls it beats are grey. This is what makes Figure 2 read at a glance.
3. Cell type (E / I) is a marker shape, not a colour: circles for excitatory, triangles
   for inhibitory. It appears only inside the rate scatters, where colour is already
   spent on truth vs model.
4. Reference lines — the noise ceiling, the teacher's dimensionality — are grey and
   dashed or dotted. They are furniture, not data.
5. Nothing else gets added here without deleting something. Five colours.


WHERE THIS LIVES IN CODE
========================

The five are defined once, in connectome_snns.visualization (SLIDE_INK, SLIDE_BLUE,
SLIDE_RED, SLIDE_YELLOW, and the neutrals). Figures never write a hex value: they import
the semantic names from common/style.py (truth, model, unobserved, control shades).

History: between 2026-09-17 and 2026-09-21 the figures drifted onto a twenty-colour
library palette, with blue meaning three different things across slides. This file
replaces that; the drift is in git history if a colour ever needs recovering.
